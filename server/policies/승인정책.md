# 결재 및 승인 정책

> 이 문서는 도구 시연용 가상 샘플입니다. 특정 회사의 실제 규정이 아닙니다.

## 1. 승인선 구성

### 1.1 기본 승인선

- 모든 휴가 신청은 1차 승인(직속 팀장) → 2차 승인(부서장) 순으로 진행된다.
- 연속 5영업일을 초과하는 신청은 3차 승인(본부장)이 추가된다.
- 승인선은 신청 생성 시점의 조직도를 기준으로 저장되며, 이후 조직 개편의 영향을 받지 않는다.

### 1.2 대결과 위임

- 승인자가 부재(휴가·출장) 상태인 경우 사전에 지정된 대결자가 승인할 수 있다.
- 대결자가 지정되지 않은 상태에서 3영업일간 처리되지 않으면 상위 승인자에게 자동 에스컬레이션된다.

## 2. 승인 처리

### 2.1 순차 처리 원칙

- 승인은 순차적으로만 진행되며, 이전 단계가 완료되지 않은 상태에서 다음 승인자는 처리할 수 없다.
- 각 단계의 승인·반려 시각과 처리자는 감사 로그에 기록된다.

### 2.2 반려 처리

- 어느 단계에서든 반려되면 신청 전체가 반려로 종료되고, 이후 단계는 진행되지 않는다.
- 2차 승인자가 반려하면 1차 승인 결과와 무관하게 신청은 종료되며, 미리 차감된 연차는 즉시 복원된다.
- 반려 시 사유 입력은 필수이며, 신청자에게 알림이 발송된다.
- 반려된 신청은 수정할 수 없고, 신규 신청으로 다시 생성해야 한다.

### 2.3 자동 승인

- 반차 이하(0.5일) 신청은 1차 승인만으로 확정되도록 부서별로 설정할 수 있다.
- 자동 승인 적용 여부는 부서 설정을 따르며, 신청자는 신청 전에 적용될 승인선을 확인할 수 있다.

## 3. 알림

- 승인 요청은 생성 즉시 현재 단계 승인자에게 발송된다.
- 미처리 건은 24시간 간격으로 리마인드되며, 3회 이후에는 발송을 중단하고 에스컬레이션한다.
